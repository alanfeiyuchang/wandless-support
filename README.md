# Wandless — support site

Support page and privacy policy for **Wandless**, a mixed-reality spellcasting game for
Apple Vision Pro. Served with GitHub Pages:

- Support: https://alanfeiyuchang.github.io/wandless-support/
- Privacy policy: https://alanfeiyuchang.github.io/wandless-support/privacy.html

Static HTML, one stylesheet, no build step. These are the URLs to give App Store Connect
(Support URL and Privacy Policy URL).
